# 蜜蜂图床

把图片上传到蜜蜂图床（https://www.beeimg.cn），返回公开直链。

插件提供两种方式，默认游客：

| 方式 | 说明 |
| --- | --- |
| 游客（不登录） | 免配置，开箱即用，图片保留 1 小时 |
| 账号（访问令牌） | 填写访问令牌后按会员身份上传，图片永久保存，额度按账号套餐 |

## 上传限制

游客图片仅保存 1 小时，注册会员可享受图片永久保存、无单次上传限制权益，建议前往 [注册账号](https://www.beeimg.cn/login) 获得更好体验。

- 支持格式：jpg、jpeg、png、webp
- 游客单文件上限 5 MB
- 游客限额：每分钟 5 张、每小时 10 张、每天 20 张、每周 30 张、每月 100 张
- 游客图片无法删除，过期后自动清理
- 图片实际存放在 `beeimg.us.ci` 域名的临时目录下
- 删除图片请到站点「我的图片」操作，插件不声明云端删除

## 使用

安装后在 Picora 添加配置：

1. 选「蜜蜂图床」。
2. 鉴权方式选「游客（不登录）」可直接上传，不必填任何内容。
3. 需要永久保存时，在鉴权方式里选「账号（访问令牌）」，填访问令牌。

因为插件包含令牌方式，配置列表会显示「需认证」标签；只用游客时不填任何字段也能正常上传。

## 获取访问令牌

1. 登录 https://www.beeimg.cn 。
2. 进入「用户中心 → 访问令牌」，新建令牌。
3. 权限勾选 `upload:write`（上传图片）与 `user:profile:read`（校验令牌）；缺少后一项会提示权限不足。
4. 复制生成的令牌填入插件；令牌只显示一次，丢失需重新创建。

## 错误对照

| 提示 | 原因 |
| --- | --- |
| 访问令牌无效或已过期，请重新生成 | 令牌填错、被删除或已过期 |
| 文件必须是一个 jpg, jpeg, webp, png 类型的文件。 | 图片格式不在支持范围 |
| 文件不能大于 5120 KB。 | 超过游客单文件上限 |
| 上传过于频繁，请稍后再试 | 触发频率限制 |
| 上传被拒绝，可能超出游客限额 | 游客每日上传次数用尽 |
